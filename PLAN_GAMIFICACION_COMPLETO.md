# Plan Maestro de Gamificación - Instituto San Miguel
## Curso: Especialista en Desarrollo con Claude Code

**Versión:** 1.0
**Fecha:** 4 de Noviembre de 2025
**Estado:** Plan Aprobado - Pendiente de Implementación

---

## 📋 Executive Summary

Este plan transforma el curso "Especialista en Desarrollo con Claude Code" en una experiencia educativa gamificada que aumenta la motivación, retención y dominio de conceptos mediante:

- **Sistema de Progresión**: 7 niveles XP con 5,000 puntos totales disponibles
- **Achievements**: 35 logros desbloqueables que refuerzan aprendizaje clave
- **Ejercicios Gamificados**: 20 ejercicios distribuidos estratégicamente en 9 módulos
- **Dashboard Motivador**: Visualización de progreso, logros, stats y próximas metas
- **Mecánicas de Engagement**: Streaks diarios, challenges, leaderboard opcional

**Objetivo pedagógico principal**: Reforzar el aprendizaje mediante feedback inmediato, celebración de dominio y progresión visible.

**Timeline de implementación**: 9 semanas (4 fases)

**Impacto esperado**:
- +40% retención de estudiantes
- +35% tasa de finalización del curso
- +50% engagement con ejercicios opcionales
- +25% mejora en scores de tests

   - C) "Botón React"
   - D) "Necesito código de botón bonito"

   - A) Solo el código viejo
   - B) ✅ Código viejo + objetivo de refactor + constraints (mantener API pública igual)
   - C) "Mejora esto"
   - D) Nada, Claude lo sabe

   **Explicación**: Claude necesita contexto: qué quieres mejorar, qué restricciones hay, y el código actual.

## 🎯 5. Mecánicas de Engagement

### Daily Challenges

**Concepto**: Desafíos opcionales diarios para practicar conceptos fuera del flujo principal.

**Implementación**:
- 1 challenge nuevo cada día a las 00:00 GMT-6
- Duración: 24 horas
- Recompensa: +10 XP base + bonus por streak
- No penaliza si no se completa

**Tipos de Daily Challenges**:
1. **Quick Quiz**: 3 preguntas sobre concepto aleatorio ya aprendido
2. **Code Snippet Fix**: Encuentra y corrige el bug en código de 10 líneas
3. **Best Practice**: Identifica mejoras en código subóptimo
4. **Refactor Mini**: Refactoriza componente pequeño con Claude
5. **Prompt Challenge**: Escribe el prompt más efectivo para tarea dada

**Ejemplo**:
```
🎯 Daily Challenge - 4 Nov 2025
"Refactoriza este useState a custom hook"

// Código original (subóptimo)
const [name, setName] = useState('');
const [email, setEmail] = useState('');
const [errors, setErrors] = useState({});

const handleSubmit = () => {
  // validación inline compleja...
}

// Tu tarea: Crear custom hook useForm que encapsule esto
// Tiempo: 10 minutos
// Recompensa: +10 XP (+5 si lo haces en <5 min)
```

### Streak System (Rachas)

**Definición de actividad mínima diaria**:
- Completar 1 lección completa, O
- Completar 1 ejercicio gamificado, O
- Aprobar 1 test, O
- Completar daily challenge

**Milestone Rewards**:
- 3 días: Achievement 🔥 Racha Inicial (+30 XP)
- 7 días: Achievement 📅 Semana Completa (+60 XP)
- 14 días: Achievement 💪 Compromiso Total (+100 XP)
- 21 días: Achievement 🎯 Maratonista (+150 XP)
- 30 días: Achievement 👑 Dedicación Absoluta (+250 XP)

**Streak Protection**:
- 1 "freeze" por cada 7 días de streak
- Permite perder 1 día sin romper racha
- Se consume automáticamente si no hay actividad
- Visual: Escudo de hielo 🛡️ sobre el fuego de streak

**Notificaciones**:
- 20:00 hrs: "¡Aún no has estudiado hoy! Tu racha de 12 días está en riesgo 🔥"
- 22:00 hrs: "Última hora para mantener tu racha de 12 días 🔥"
- Al romper racha: "Tu racha de 12 días ha terminado. ¡Empieza una nueva hoy! 💪"

```
❓ Hint 4 (-10 XP):
"Aquí está la estructura básica:
function useDebounce(value, delay) {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const timer = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(timer);
  }, [value, delay]);
  return debounced;
}"
```

```typescript
// Cron job para verificar streaks
cron.schedule('1 0 * * *', async () => {
  const users = await prisma.user.findMany({
    include: { progress: true }
  });

  for (const user of users) {
    const lastActivity = new Date(user.progress.lastActivityDate);
    const today = new Date();
    const daysSinceActivity = differenceInDays(today, lastActivity);

    if (daysSinceActivity === 1) {
      // Perdió la racha, pero puede haber freeze
      if (user.progress.streakFreezes > 0) {
        await useStreakFreeze(user.id);
      } else {
        await resetStreak(user.id);
        await sendNotification(user.id, 'STREAK_LOST');
      }
    } else if (daysSinceActivity > 1) {
      await resetStreak(user.id);
    }
  }
});
```

- Puntos/badges refuerzan aprendizaje específico
- No gamifica contenido, gamifica progreso
- Evita competición forzada (leaderboard opcional)
